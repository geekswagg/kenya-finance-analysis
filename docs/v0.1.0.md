# v0.1.0 release criteria

- Confirm and register the 11 National Treasury documents covering FY 2021/22 through FY 2026/27.
- Inventory and reconcile the foundational dataset against the registered sources.
- Run reproducible extraction and transformation to produce CSV and JSON with source locators, status, and publication vintage.
- Validate data types, reference integrity, uniqueness, missingness and CSV/JSON parity in GitHub Actions.
- Verify representative DuckDB queries, publish the discrepancy log and record coverage gaps.
- Review publication rights and private information before tagging a release.
