# Contributing

Open or claim an issue before starting a change. Submit a focused pull request with the issue link, the checks you ran and any unresolved discrepancies.

For a data change, include the official source URL, publication edition, SHA-256 of the input, and a reproducible locator for each observation. Explain changes to units, fiscal-year labels, estimate status and missingness. Compare conflicting figures before changing the published series.

Keep unreviewed files in the ignored `data/incoming/` directory. Review file contents and metadata for private information before staging anything. Link official documents by default and include copies only when redistribution terms permit it.
