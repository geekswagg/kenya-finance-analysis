# Engineering instructions

- Work through GitHub issues and pull requests. Link the issue and include verification evidence.
- Record source document edition, page or table, row or line item, reporting period, as-reported label, unit, scale and observation status for each value.
- Keep actuals, projections and revised estimates distinct. Preserve different publication vintages.
- Preserve missing values with their source meaning. Never infer zero from a blank.
- Record disagreements with both source references and the resolution status.
- Review files and metadata for private information and verify redistribution rights before publication.
- Keep Python data checks reproducible. Build the API and dashboard after the foundational release.
